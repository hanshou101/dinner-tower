## 1. 风格预设

- 预设：`mission-control`（`design/tokens.css`）——近黑底、琥珀信号色、机场出发屏。
- 为什么选它（赛题、主办方、评委、目标用户）：评委第一眼看到的应该是「一块在厨房里工作的出发看板」，不是一张网页。近黑底 + 琥珀单色信号与机场出发屏同构，评委不用读文案就知道这是什么；保留出发看板这个隐喻——它是三场作品里唯一接近过线的一屏（D1 打分 21/30）。
- 主办方品牌色是否替换 accent：否。`--accent: #F5A524` 原样保留，`python3 scripts/check_tokens.py` 通过（见第 5 节）。作品用「for Alexa+」字标说明归属，不再抢第二块颜色。
- 字体随仓库自带：`design/fonts/`（Barlow、Barlow Semi Condensed、JetBrains Mono，woff2 latin 子集，@fontsource 5.3.0 发布包，OFL-1.1），不走 CDN。

## 3. 记忆点（signature moment）

评委看完视频还记得的那个画面：**视频约 2:00，用户说「the turkey needs twenty more minutes」之后**，设备屏幕里的出发看板 9 行步骤依次滑动到新时间（单行 400ms 的 FLIP 位移、逐行错开），NOW 行换位；同时舞台顶部跳出琥珀大字 **「SERVE 7:20 PM」**，跳动一次后停住。

为什么是它：这一屏同时证明了产品的主张（全部重排）与技术的真实（看板是 App，自己算、自己动），不需要旁白解释——观众看见时间在动就懂了。这是视频里最该被记住的 5 秒。

## 4. 主屏视觉规格（hero screen，视频里停留最久的那一屏）

- 画布：1280×720（视频帧）一屏装下，不滚动。1440×900 只做等比留白，布局不变。
- **演示模式是默认。** 开发者信息全部收进 `?dev=1` 才出现的「Developer」面板：页头版本与 session 那条胶囊、AGENT MODE 与模型名、TOOLS 清单、TOOL CONSOLE、原始 JSON、SYSTEM 卡。录视频、截图一律用演示模式。
- 栅格与区块：

  | 区块 | 位置 | 尺寸 | 内容 | 层级 |
  | --- | --- | --- | --- | --- |
  | 顶栏 | 顶部通栏 | 56px 高 | 左：「Dinner Tower」字标 + 小标签「for Alexa+」；右：一个琥珀描边小胶囊「DEMO CLOCK 6:20 PM」（诚实标注，保留） | 第 3 眼 |
  | 舞台 | 左 | 约 820px 宽 | 一台 Echo Show 风格的设备框（深灰圆角边框，屏幕 16:10） | 第 1 眼 |
  | 设备屏幕 | 舞台内 | 约 788×492 | 空闲：大钟 + 一行 `Try: "Alexa, plan Thanksgiving dinner for 7 PM"` + 三个示例说法胶囊；有方案：出发看板铺满 | 第 1 眼 |
  | 对话栏 | 右 | 约 380px 宽 | 标题「Conversation」+ 用户 / Alexa 两种气泡 + 每条 Alexa 回复下的工具胶囊 | 第 2 眼 |

- **出发看板就在设备屏幕里，是全片主角。** 不再有七成面积的空舞台。
- **对话栏**：正文 18px；只显示最近 3 轮；每条 Alexa 回复下面一个小号灰色「工具胶囊」，例如 `⚙ report_delay · 6 ms`，代表这一轮调用了哪个 MCP 工具——**不显示 JSON**。
- **反问（elicitation）**：画在设备屏幕里面，像 Echo Show 自己的选择卡（两个大按钮），不是漂在空舞台上的弹窗。
- **字幕**：视频字幕只用于旁白，放在舞台底部的安全区，不压住对话栏；对话内容已经在对话栏里，不再重复成字幕。
- **看板加强**：菜式前的 emoji 换成小色点（每道菜一个固定颜色）；NOW 行整行琥珀淡底 + 左侧 3px 琥珀竖条；DONE 行降到 50% 不透明；底部炉灶时间轴高度加倍，轴标签 ≥ 14px。
- 字号：只用 `--fs-*` 中的 4 级——
  - `--fs-xl`(28px)：空闲大钟（这一级的唯一用法）；
  - `--fs-lg`(20px)：看板 SERVE 时间、设备屏幕引导语；
  - `--fs-md`(16px)：看板 STEP 行、对话正文（对话正文按 18px 单列，见下）；
  - `--fs-sm`(14px)：看板时间轴刻度、工具胶囊、对话里的次要标签；
  - `--fs-xs`(12px)：小节标签（Barlow Semi Condensed 大写、字距 0.08em）、看板表头。
  - 视频里不出现小于 14px 的文字。
- 颜色：只用 `mission-control` 预设变量；强调色 `--accent`（琥珀）只给「现在这件事」——看板 SERVE 时间、NOW 行、DEMO CLOCK 胶囊。成功 / 警告 / 危险色只表达语义。
- 状态：空 / 加载 / 正常 / 异常——
  - 空：设备屏幕里是大钟 + 一句引导 + 三个示例胶囊，绝不空着；
  - 加载：设备屏幕底部的光条扫动；
  - 正常：出发看板；
  - 异常：看板底部一条人话错误条（例：「The board could not reach the server」），不出现堆栈。
- 控件：checkbox、时间输入框、下拉框按预设重画；演示模式里能不出现就不出现（时间输入框与下拉框只在 `?dev=1` 出现）。
