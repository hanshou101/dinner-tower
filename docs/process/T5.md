## 6. 偏差与建议

- E2E 的測試宿主不吃 `App` 的 autoResize：Echo 螢幕固定 880×550，讓 iframe 跟著 App 上報的高度長大會把時間軸切掉。宿主固定 iframe 尺寸，App 端靠 flex 收縮表格。
- `+10 MIN` 的 E2E 回應用的是 `delayed.json`（表 C，9 項變動），因為 SPEC §6.2.6 只給了 AC-8（turkey.roast +10 → 19:10）的上菜時間、沒有逐步驟黃金表；不自創沒有出處的逐步驟數字。真實 server 的 +10 流程由 `test:real` 驗（結果正好也是 9 項變動、SERVE 7:10 PM）。
- 建議（不在本票範圍）：衝突橫幅佔兩行高度，目前靠把列高從 25px 收到 22px 才塞得進 550px；若之後要在大字體主機上跑，可考慮把兩個選項按鈕改成橫排一行。
