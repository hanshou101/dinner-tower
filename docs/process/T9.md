## 2. 测试先失败（命令 + 输出）

本票交付的是流水线与文档，没有「先写单元测试再实现」的顺序；对应的红是两次真实失败，都把流水线挡在成片之前，另有第一次看成片时发现的一组画面问题。

### 2.1 配音助手在 bash 3.2 下直接崩

```text
$ bash scripts/demo/voice.sh --one narrator /tmp/narrator.aiff
scripts/demo/voice.sh: line 96: used[@]: unbound variable
```

macOS 自带 bash 3.2 + `set -u` 时，空数组的 `"${used[@]}"` 会被当成未定义变量。改成 `local used=(); [ "$#" -gt 0 ] && used=("$@")` 与 `${used[@]+"${used[@]}"}` 的写法后通过；`--list` 输出 `narrator=Samantha`、`user=Reed (英语（美国）)`、`alexa=Flo (英语（美国）)`。

同一次还发现 `say -v '?'` 的名字带本地化后缀（`Reed (英语（美国）)`），按 `^名字 +en_US` 匹配会全部落空，最后误选到玩笑音色 `Fred`；改为按语言列取 en_US、去掉括号后缀做 base→full 映射、并过滤 novelty 音色。

### 2.2 第一次全流程录完 165 秒，成片在保存时丢了

```text
$ bash scripts/demo/make.sh
…
recorded 165.0s of wall clock, 86.9s of speech
Error: video.saveAs: Target page, context or browser has been closed
```

Playwright 的录像在 `context.close()` 时封盘，但 `browser.close()` 之后 `video.saveAs()` 的句柄已失效。把 `saveAs()` 挪到 `context.close()` 之后、`browser.close()` 之前后，得到 `capture.webm`（1280×720 vp9，165.00 s）。

### 2.3 第一次看成片时，画面有四处不能用

- 字幕压在看板时间轴上，且不居中 → 字幕条移到底部 26 px、`left:0;right:0;margin:0 auto;width:max-content` 居中；
- 红色 `SAMPLE` 角标盖住了顶栏的 `DEMO CLOCK` 控件 → 改成底部整条红色横带，不再遮挡任何控件；
- Alexa 气泡读出来是「Alexa Alexa …」→ 角色标签的 `text-transform: uppercase` 让 `innerText` 返回 `ALEXA`，正则改成 `/^\s*ALEXA\s*/i`；
- 鼠标指针每次从左上角飞入 → 首次显示直接定位，点完隐藏。

（这几条同时记进 `docs/friction/T9.md`。）
