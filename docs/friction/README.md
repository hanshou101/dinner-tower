# docs/friction：真实踩坑记录（friction log）

Devpost 规则：提交 friction log 最高可加 10% 评分（docs/00-BRIEF.md §2 #10）。每张票把**亲手遇到**的坑写进自己的 `Tn.md`，包装票（T9）汇总成英文提交栏位。没遇到就写「无」，**不许编造**。

每条格式（英文）：

```markdown
### <short title>
- Tool / API / SDK: <name + version>
- Task attempted:
- Steps taken:
- Expected:
- Actual: <error text verbatim if any>
- Severity: Blocker / Major / Minor
- Workaround:
- Actionable suggestion:
```
